BALLIN — PAQUETE PARA GITHUB PAGES (versión actual)
===================================================
Repositorio: ballin-studio/ballinstudio

QUÉ HAY
  index.html, support.js, crystal3d.js, manifest.webmanifest, .nojekyll
  assets/          imágenes, favicon, pósters de reels, crystal-shape.json
  videos/          10 reels completos
  videos/preview/  10 previews ligeras (en bucle, sin audio)

CÓMO SUBIRLO
  1. Descomprime. Arrastra el CONTENIDO (no la carpeta que lo envuelve).
  2. github.com/ballin-studio/ballinstudio → Add file → Upload files
  3. Tanda 1: index.html, support.js, crystal3d.js, manifest.webmanifest,
     .nojekyll y la carpeta assets → Commit changes
  4. Tanda 2: la carpeta videos (incluye preview/) → Commit changes

  Sobrescribe los archivos antiguos con el mismo nombre. No hace falta borrar nada.
  .nojekyll oculto en Mac: Cmd + Shift + . en el Finder.

Si Pages no está activo: Settings → Pages → Deploy from a branch → main / (root).
Tarda 1-2 min en actualizarse. Si ves la versión vieja, recarga con Cmd + Shift + R.
